# KW7H Website Clone

This is a Next.js project that clones the website https://kw7h.com/ using reusable components and Tailwind CSS.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `app/page.tsx`: Main page component
- `components/`: Reusable components for the website sections
  - `Hero.tsx`
  - `AboutUs.tsx`
  - `LeadershipTeam.tsx`
  - etc.

## Build

To build the project:

```bash
npm run build
```

## Deploy

Deploy on Vercel or any hosting platform that supports Next.js.
